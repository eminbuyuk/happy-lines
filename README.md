# Happy Lines

Public product website and policy pages for Happy Lines.

Live site: https://eminbuyuk.github.io/happy-lines/
Full version: https://eminbuyuk.github.io/happy-lines/lifetime.html

Current collection: 50 free stops; 260 stops in the full version, including the free collection. Five languages. One-time Google Play purchase; no subscription. The app is currently in closed testing.

This repository publishes the website, representative game screenshots and compressed promotional artwork. It does not include the Android app or its game source code.
